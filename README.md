## 🚀 Featured projects

### Skip-Trace Prioritisation with Ageing Hidden Markov Models
**Open IIT Data Analytics Competition 2026 · Top 10 finalist · Team Data401**

[View repository](https://github.com/124-CE/CreditNirvana-ps2-rpc-skiptrace)

- Worked with approximately 51,000 debt-collection call records to predict right-party contact and prioritise skip-tracing actions.
- Built a continuous-time Hidden Markov Model using matrix exponentials to model time-dependent state transitions and ageing evidence.
- Combined HMM-derived beliefs with gradient boosting and isotonic probability calibration.
- Implemented a Value-of-Information policy for cost-sensitive action selection.
- In the held-out evaluation reported by the team, the policy increased the skip-trace hit rate from **25.1% to 46.3%** while reducing expenditure from **₹25.3k to ₹5.6k**.
